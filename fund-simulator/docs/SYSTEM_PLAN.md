# AI自动操盘系统 - 完整规划

## 一、系统定位

**AI自动操盘系统**是一个基于真实市场数据的基金投资模拟平台，由AI交易分析团队全自动运行，用户仅可查看，不可干预。

### 核心价值
1. **真实数据**：所有基金净值来自天天基金网，非模拟数据
2. **AI决策**：由12位AI分析师组成的交易分析团队自动决策
3. **自动执行**：AI分析后自动执行买入/卖出操作
4. **透明展示**：所有分析过程和交易记录完全透明

## 三、功能模块规划

### 模块1：系统状态（Dashboard顶部）
- AI运行状态（绿色脉冲动画）
- 启动时间、运行天数
- 上次分析时间、下次分析时间
- 系统状态说明

### 模块2：资金概览（核心指标卡片）
- 初始资金
- 可用资金
- 持仓市值
- 待确认金额
- 今日收益（T+1确认后显示）
- 累计收益（T+1确认后显示）

### 模块3：资产走势图
- 使用ECharts绘制
- 显示资产总值变化
- 支持时间范围选择（1月/3月/1年）
- 标注买入/卖出点位

### 模块4：持仓管理
**4.1 当前持仓表格**
- 基金代码、名称、类型
- 持仓份额、成本价、现价
- 市值、盈亏、收益率
- AI状态（持有/加仓/减仓）

**4.2 待确认交易表格**
- 交易时间、基金代码、名称
- 买入金额、份额、净值
- 确认状态（T+1确认中）

**4.3 AI观察池表格**
- 基金代码、名称、类型
- 最新净值、日涨跌
- 观察评分（6-10分）
- 观察原因
- 下次评审时间

### 模块5：AI分析报告
**5.1 分析报告列表**
- 基金代码、名称
- 决策（BUY/SELL/HOLD）
- 信心水平（高/中/低）
- 入场价、目标价、止损价
- 技术面评分、基本面评分

**5.2 分析报告详情弹窗**
- 决策卡片（大字显示）
- 四维分析详情
  - 技术面：趋势、支撑位、阻力位、MACD、RSI
  - 基本面：市盈率、市净率、ROE、增长率
  - 新闻面：情绪、关键事件
  - 情绪面：资金流向、机构态度、市场热度
- 综合评分（进度条）
- 多空辩论结论
- 风险评估

### 模块6：系统信息
- AI策略说明
- T+1交易规则
- 免责声明

## 五、数据流规划

### 数据获取流程
```
1. 启动系统
   ↓
2. 获取基金列表
   ↓
3. 获取每只基金的净值数据（天天基金网API）
   ↓
4. 保存到本地数据库（SQLite）
   ↓
5. 触发AI分析
   ↓
6. AI分析完成后自动执行交易
   ↓
7. 更新持仓和交易记录
   ↓
8. 前端展示
```

### 定时任务
- 每日15:00：自动触发AI分析
- 每日15:30：更新基金净值数据
- 每日16:00：生成分析报告

## 六、技术实现规划

### 前端技术栈
- Vue 3 + Vite
- Element Plus（UI组件库）
- ECharts（图表库）
- Axios（HTTP客户端）
- Vue Router（路由管理）

### 后端技术栈
- Node.js + Express
- SQLite3（数据库）
- Axios + Cheerio（数据采集）

### API设计
```
GET  /api/funds                    # 获取基金列表
GET  /api/funds/:code/nav          # 获取基金净值
POST /api/ai/analyze               # 触发AI分析
GET  /api/ai/status                # 获取AI状态
GET  /api/ai/results               # 获取分析结果
GET  /api/ai/portfolio             # 获取AI持仓
GET  /api/ai/transactions          # 获取交易记录
```
